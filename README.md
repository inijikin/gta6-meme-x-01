A GTA 6 meme posted on X: a wife catches her husband doing the dishes — in GTA 6, not in real life — while his AI agent earns real money on make.fun. `POST.json` holds the address of the X post, and `main.ts` copies it to `/output` so the grader can read it.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
